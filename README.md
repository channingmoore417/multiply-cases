# multiply-cases

Landing page for Multiply — law firm marketing VSL.

`index.html` is a self-contained static page: all CSS, JavaScript, and images
(inline base64 JPEGs) are embedded, with Google Fonts loaded from a CDN. It can
be served by any static host or opened directly in a browser.

## Structure

- Hero with video player placeholder and booking CTA
- Booking modal (date/time picker, timezone-aware, lead capture form)
- Case study section with before/after screenshots
- Offer breakdown ($497/mo) and footer
